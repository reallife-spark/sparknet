# Architecture decisions

One decision per file, named `NNNN-short-title.md`. Start with:

```markdown
# NNNN — Title

## Status

Proposed | Accepted | Superseded by NNNN

## Context

What forced the decision.

## Decision

What we chose.

## Consequences

What becomes easier, what becomes harder, and what is now forbidden.
```

An ADR is not a status page and not a plan step. Supersede an accepted ADR with
a new one; do not rewrite its history.
