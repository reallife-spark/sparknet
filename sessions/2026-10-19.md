## The review pass: what it found

### 1. The one bug that would have failed the first real build

`goagx/sparknet.agx.docker` declared `ARG TARGETARCH` **before the first
FROM**. Empirically pinned (3 build experiments at `/tmp/opencode/argtest/`):

- Dockerfile `ARG` before `FROM` expands **EMPTY** inside stage `RUN`s
  (patterns A/B: `arch=[]`).
- A **bare in-stage `ARG TARGETARCH`** auto-fills BuildKit's predefined value;
  in-stage redeclaration of a global-defaulted ARG inherits the global value
  (pattern C: `arch=[arm64] def=[hello]`).
- `docker build --check` does **not** catch this class — lint never evaluates
  `RUN`.

Symptom would have been `unsupported TARGETARCH: ` (empty) at the NATS step,
hours into the build. **Fixed:** global ARG removed, stage-local
`ARG TARGETARCH` added with a why-comment. `spark.docker` was already correct
(`ARG TARGETARCH` in-stage at line 58).

**Structural improvement:** `test_agx_node.py` now has a stage-scope checker —
joins backslash continuations, walks stages, and fails if a RUN/COPY/ENV/
LABEL references a name that is only global/pre-FROM (or a predefined platform
arg) and not redeclared in-stage. Only global/predefined names are flagged, so
shell variables like `$asset` don't false-positive. Self-tests pin six
synthetic shapes (incl. continuation and `ENV`-ref cases) and both real
Dockerfiles are parametrized through it.

### 2. False alarms, empirically cleared

- **`wait -n "$wpid" "$shim_pid"` on bash 5.0** (the entrypoint's supervisor):
  tested in `ubuntu:20.04` — works with pid args; already-dead child →
  rc=143, no error. No change needed.
- **`--engine stub` + `--platform agx` state-host wiring:** setup writes
  `SPARKNET_STATE_HOST=$NODE_STATE` into the env file and `compose()` passes
  `--env-file` whenever present → no relative-path bug. No change needed.
- **`s/^torch.*/torch/` sed collateral:** fetched vLLM v0.2.7
  `requirements.txt` — pins `torch == 2.1.2`, `xformers == 0.0.23.post1`,
  `transformers >= 4.36.0`; **no `torchvision` line exists**, nothing else
  starts with `torch`. The dockerfile's comments about those pins are accurate.
- **`.dockerignore` vs AGX COPY sources:** bundle negation rule intact,
  `spark-entrypoint.sh` / `spark-precontext.py` / `goagx/*` all unfiltered.

### 3. Fixed during review

- **shellcheck parity:** the gate *skips silently* when the binary is absent
  (host has none) while GitHub Actions runs it — got v0.11.0
  (`/tmp/opencode/bin/shellcheck`, the `v0.10.0.linux.aarch64` asset 404s) and
  ran the gate with `PATH` prefix: **all 44 tracked scripts clean.**
- **Shim upload was unbounded:** `await file.read()` would buffer any upload
  into RAM on a 16 GB machine. Now chunked with a cap
  (`WHISPER_MAX_UPLOAD_BYTES`, default 512 MiB) answering **413**; asserted by
  the audio-surface test. `ast.parse(feature_version=(3,8))` + `compile`
  proven clean (walrus-free loop, local `list[bytes]` annotation never
  evaluated on py3.8).

### 4. Compose/shim spot-checks that passed

Healthchecks hit the honest ports (audio: shim `:8003/health`, which relays
whisper's own `/health`; embed/rerank: llama-server `/health`), `restart:
unless-stopped` means any entrypoint exit restarts the container (exit code
irrelevant — no on-failure trap needed), `VLLM_SERVICE_CMD` = `vllm` /
`vllm-stub` written by setup for both platforms, manual-path commands in the
