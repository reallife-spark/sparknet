## 92A — Decision

Adopted. Python is the one graph producer; Go is the graph consumer.

- Python owns `scan`, `build`, `merge`, `normalize`, `validate` and `diff`.
- The seam is the path-stable `shared/sparknet-understand.py` JSON CLI. Go does
  not import an installed package and no long-lived worker is added.
- Go keeps `query`, `export` and MCP; `scan`, `diff` and `parse` are adapters.
  `gofrag` keeps `go/parser` but consumes Python `FileRecords`.
- Python owns scan policy: excludes, `.understandignore`, language/test maps,
  binary detection and the 2 MB cap.
- Go preserves raw graph fidelity for export; typed structs are a query
  projection; `Diff` is Python's result.
- Missing or failing Python fails closed for production commands; query/export/
  MCP over an existing graph still work; no silent Go fallback.
- `sparknet-understand` becomes an intentional `gospark` build and goagx
  artifact; a root `understand-check` and one cross-language fixture prove
  parity. Role bundles include it only if a role surface invokes it.
- ADR-0017 is superseded by `gospark/docs/adr/0018-understand-graph-producer.md`.
- No `design-it-twice`: the seam was not contested after the CLI decision.

## 92B — Decision

Adopted. One shared issue module.

- `shared/sparknet-issue.py` is the path-stable facade; `shared/sparknet_issue/`
  owns parsing, redaction, validation, ledger/latest view, triage transitions
  and the read projection.
- `shared/sparknet-authz.py` remains the envelope/signature owner; the issue
  module calls it but never signs, grants or installs.
- Peer, Master and console become adapters. The console stays read-only.
- Triage transitions are now in scope: append-only `triage.jsonl` plus a
  derived `triage.json`; a small Master-local CLI writes transitions.
- One redaction policy table; peer checks before signing, Master checks before
  storing.
- The wire contract is unchanged; the local-store section is corrected for the
  triage ledger and derived view.
- Existing JSONL and `triage.json` are read and seeded; no history rewrite.
- Recorded as root `docs/adr/0009-issue-module.md`; GLOSSARY names issue module,
  issue projection and triage ledger.
- No `design-it-twice`: the module seam was settled by the shared-location and
  authz-boundary decisions.

## 92D — Decision

Adopted. Four modules behind the path-stable core facade:

- `schema.py` — contract loading, vocabulary, canonicalization, IDs and
  constructors.
- `production.py` — scan policy, `FileRecord`/`ScanResult`, project metadata and
  framework detection.
- `algebra.py` — normalize, merge, validate, diff, layers, tour and output
  helpers.
- `core.py` — path-stable facade re-exporting existing public symbols.
- `build.py` stays the orchestration seam; internal callers import the narrow
  module they need; external callers keep the facade.

Design-it-twice compared three maps: a minimal two-module map, a flexible
six-module map with `kinds`/`io`, and the four-module common-caller map. The
minimal map mixed scan policy with algebra; the flexible map created one-adapter
seams. The four-module map won on depth, locality and the deletion test.

The three design subagents failed to connect to the API, so the comparison was
run directly against the same three constraints.

Recorded as root `docs/adr/0011-understand-core-split.md`; GLOSSARY names graph
production and graph algebra.
