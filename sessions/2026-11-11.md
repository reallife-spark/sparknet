## Step 101 — malformed-gateway degradation

- Bug chosen by robustness probe (no reported bug): a fake gateway returning a
  JSON list made `/api/evals` and `/api/projects` drop the connection.
- Phase 1 loop: `tests/test_webui_console.py::test_evals_route_degrades_when_the_gateway_returns_a_non_object`
  (fake gateway returning `[]`), RED on `AttributeError: 'list' object has no
  attribute 'get'` in `_local_gateway_runs`.
- Hypotheses ranked: non-dict payload (confirmed by traceback); non-list `runs`
  (already safe); token/HTTP failures (already caught).

  and `runs` is a list. Regression covers `/api/evals` and `/api/projects`.
- Full suite, lint and format green. No debug instrumentation left.

## Step 102 — malformed run record refusal

- Chosen by the same robustness probe: the run view can carry a non-object
  `result` or `task`.
- Phase 1 loop: `tests/test_project_script.py::test_report_refuses_a_malformed_run_record`
  (fake gateway returns `result: []`, then `task: "..."`), RED on
  `AttributeError: 'list' object has no attribute 'get'` at
  `scripts/sparknet-project.py:428`.
- Hypotheses: non-dict `result` (confirmed by traceback); non-dict `task`;
  missing values were already handled by the old `or {}`.
- Fix: `cmd_report` refuses unless both are objects, before the review gate and
  before any write. Both variants now exit with
  `run record is malformed: result and task must be objects`.
- Full suite, lint and format green; no debug instrumentation.

- Release: fabric `a84529f`, goagx `62797c6` pinned; `make drift-check` green.
